# SpendingSaver specification

[`SPEC.md`](SPEC.md) is the product-level specification for the projects in
this repository. It separates intended behavior from verified implementation
status and records unresolved product decisions.

The spec is a draft, not an assertion that every requirement is already
implemented. Use each project's README for setup and the root
[`TODO.md`](../TODO.md) for confirmed engineering follow-ups.
